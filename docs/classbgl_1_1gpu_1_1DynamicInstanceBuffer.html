Detailed Description

Dynamic WebGPU slot-1 instance matrix vertex buffer keeping an identity matrix permanently at index 0.

Keeping glm::mat4(1.0f) at byte offset 0 allows non-instanced draws (startIdx = 0) and batched instanced draws (startIdx >= 1) to share the same 2-slot pipeline without firstInstance indirect draw extensions.
