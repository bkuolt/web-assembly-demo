Traverses the spatial tree, performing frustum culling and front-to-back Hi-Z occlusion culling.

Parameters

viewProjCamera view-projection matrix used to project AABB bounds into NDC screen tiles.
enableOcclusionCullingWhether conservative Hi-Z tile occlusion testing is active.
lodBiasScreen-space error multiplier scaling LOD selection distances.
Returns
Vector of visible QuadtreeItems sorted front-to-back.
