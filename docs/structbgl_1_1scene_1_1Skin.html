Computes skinning joint matrices for a mesh instance: jointMatrix[i] = inverse(meshNodeWorldTransform) * jointNodeWorldTransform[i] * inverseBindMatrix[i].

Parameters

allNodesGlobal scene node list to lookup joint node transforms.
outJointMatricesDestination span of matrices (typically 128 elements).
Returns
Number of joint matrices written.
