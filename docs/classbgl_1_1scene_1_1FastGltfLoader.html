Detailed Description

SIMD-accelerated glTF asset loader and scene graph assembler.

Coordinates parallel image decoding, accessor ingestion, MikkTSpace / Lengyel tangent generation, flat normal synthesis, punctual light extraction, and node hierarchy construction into an engine Scene representation.
