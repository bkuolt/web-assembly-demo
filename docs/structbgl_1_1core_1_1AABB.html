AABB bgl::core::AABB::Transformed ( const glm::mat4 & transform) const
inlinenodiscardnoexcept

Transforms the Axis-Aligned Bounding Box by an affine 4x4 matrix using Arvo's algorithm.

Computes the new center and transformed extents via scalar absolute dot products: c' = M * c e'_k = sum_j (|M_jk| * e_j) This eliminates the need to compute, transform, and bound 8 separate corners, maintaining high performance during scene graph traversal and hierarchical culling.

Parameters
transform4x4 affine transformation matrix.
Returns
Newly computed enclosing Axis-Aligned Bounding Box in target space.
