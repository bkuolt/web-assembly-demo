Detailed Description

Standalone C++23 WebAssembly engine bridge compiled via Emscripten to web/dist/bgl_engine.wasm.

Designed for direct instantiation with WebAssembly.Memory({ initial: 256, maximum: 1024 }) under { env: { memory } } with zero WASI or host-JS stub imports.
