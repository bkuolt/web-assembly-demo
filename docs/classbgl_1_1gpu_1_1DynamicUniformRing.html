Detailed Description

template<typename T>
class bgl::gpu::DynamicUniformRing< T >

Persistent, dynamically-resizable GPU ring buffer for 256-byte aligned per-draw uniforms.

Batches all draw uniforms for a pass into one queue write and binds via dynamic offsets.
