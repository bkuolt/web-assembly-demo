void bgl::core::InstallCrashHandler ( )
noexcept

Installs POSIX signal handlers for fatal crash signals.

Intercepts SIGSEGV, SIGABRT, SIGFPE, SIGILL, and SIGBUS to output a full diagnostic report, process telemetry, and stacktrace before passing control back to the operating system.
